# Service Photos Directory

Drop photos for individual service categories into this folder (`/public/images/services/`).

## Expected File Names

| Service | Expected File Name | Recommended Size | Aspect Ratio |
|---|---|---|---|
| Manual Therapy | `manual-therapy.jpg` | 800 x 600 px | 4:3 |
| Exercise Therapy | `exercise-therapy.jpg` | 800 x 600 px | 4:3 |
| Sports Rehabilitation | `sports-rehabilitation.jpg` | 800 x 600 px | 4:3 |
| Post-Surgery Rehabilitation | `post-surgery-rehabilitation.jpg` | 800 x 600 px | 4:3 |
| Neck & Back Pain Relief | `neck-back-pain.jpg` | 800 x 600 px | 4:3 |
| Geriatric Physiotherapy | `geriatric-physiotherapy.jpg` | 800 x 600 px | 4:3 |

Supported formats: `.jpg`, `.jpeg`, `.webp`, `.png`
